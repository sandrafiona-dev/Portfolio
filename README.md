## 📦 Quick Start
 
```bash
git clone https://github.com/sandrafiona-dev/Portfolio.git
cd Portfolio
npm install
npm run dev        # → http://localhost:5173
npm run build      # production build
```
 
> **Windows:** use `start-portfolio.bat` or `serve-portfolio-8000.bat`
